Script Details

splitandsave_outcars.py

递归搜索 OUTCAR 文件，按指定比例随机分割为训练集和测试集。

交互式 Author: Zemeng Feng 2023-08-23
# python splitandsave_outcars.py # 按提示输入： # ① 包含 OUTCAR 的根目录路径 # ② 训练/测试分割比例 (e.g. 9 1) # ③ 输出目标目录路径

vasp2exyz.py

多进程并行扫描所有 OUTCAR，提取收敛结构的能量/力/应力/晶胞，合并写入一个 extxyz 格式文件。

argparse Author: G.J.Wang
python vasp2exyz.py -i <input_dir> -o <output.xyz> # 默认: # -i alloutcar # -o train.xyz # 示例: python vasp2exyz.py -i ./my_outcars -o dataset.xyz

xyz2poscars.py

将多帧 XYZ / CIF / POSCAR / CONTCAR 的每一帧转换为独立 POSCAR 文件，支持帧范围选择和帧间隔（步长）。

交互式 Author: Zemeng Feng
# python xyz2poscars.py # 按提示输入： # ① 包含原子文件的根目录 # ② 输出目标目录 # ③ 是否跳过单帧文件 (y/n) # ④ 帧范围 (e.g. 20-50,70-80) # ⑤ 帧间隔 (每 N 帧取 1 帧)

xdatcar2poscars.py

从 VASP XDATCAR 分子动力学轨迹中提取指定帧（默认最后一帧，或用户自定义范围+步长），保存为 POSCAR 文件。

交互式 Author: Zemeng Feng 2023-08-23
# python xdatcar2poscars.py # 按提示输入： # ① 包含 XDATCAR 的根目录 # ② 输出目标目录 # ③ 是否只提取最后一帧 (y/n) # 若 n：输入起始步数、结束步数、帧频率

poscars_perturb.py

使用 dpdata.System.perturb() 对 POSCAR 进行结构微扰（晶胞和原子位移），支持多种扰动样式，多核并行处理。

交互式 Author: Zemeng Feng 2023-08-25
# python poscars_perturb.py # 按提示输入： # ① 包含 POSCAR 的根目录 # ② 输出目标目录 # ③ 每个 POSCAR 生成的扰动数量 (默认 2) # ④ 是否修改扰动参数 (y/n) # 若 y：cell_pert_fraction (默认 0.02), # atom_pert_distance (默认 0.5), # pert_style (normal|uniform|const) # ⑤ CPU 核心数

poscars_omit.py

从 POSCAR 文件中随机移除指定数量的原子（默认 1–3 个），生成"挖空"结构。

交互式 Author: Zemeng Feng 2023-08-23
# python poscars_omit.py # 按提示输入： # ① 包含 POSCAR 的根目录 # ② 输出目标目录 # ③ 是否指定移除原子数范围 (y/n) # 默认: 随机 1–3 个

start_poscars.py

遍历 POSCAR 文件夹，自动生成 INCAR（PBE-D3 泛函固定参数）和 Slurm 作业脚本 runvasp.sh，通过 qvasp + sbatch 提交 VASP 作业。

交互式 Author: Zemeng Feng 2023-08-23
# python start_poscars.py # 按提示输入： # ① 包含 POSCAR 文件夹的根目录

start_xdatcar1.py

将 CIF / XYZ / POSCAR / CONTCAR 转换为 POSCAR，创建 *_AIMD 目录，生成 NVT AIMD INCAR（Nose-Hoover 50K→1500K 升温）和 Slurm 脚本，自动提交作业。

交互式
# python start_xdatcar1.py # 按提示输入： # ① 包含 CIF/XYZ/POSCAR/CONTCAR 文件的根目录

rerun_historyjobs.py

检查已完成/失败的 VASP 作业：已完成则跳过；EDIFF 未收敛则自动将 NELM 增加 400 后重提交；半路失败则直接重提。同时修正 POSCAR 格式和对称性问题。

交互式 Author: Zemeng Feng 2023-08-23
# python rerun_historyjobs.py # 按提示输入： # ① 包含 POSCAR 目录的根路径

check_nelm.py

扫描目录树中同时有 OUTCAR + CONTCAR 的文件夹，检查最后一次 SCF 迭代是否达到 NELM 上限（默认 60），列出未收敛的作业。

argparse
python check_nelm.py -i <input_dir> [-n <nelm_threshold>] # -i 必填，要扫描的目录 # -n NELM 阈值，默认 60 # 示例: python check_nelm.py -i ./jobs -n 100

checkout_nelm.py

全面的 OUTCAR 健康检查：未收敛（达 NELM）、OUTCAR 不完整（缺 General timing）、缺 CONTCAR、缺 OUTCAR 四项检查。

argparse
python checkout_nelm.py -i <input_dir> [-n <nelm_threshold>] # -i 输入目录，默认 . # -n NELM 阈值，默认 60 # 示例: python checkout_nelm.py -i ./jobs python checkout_nelm.py -i ./jobs -n 80

select_python.py

从文件夹中随机抽取指定数量的 POSCAR 文件，保存到编号子目录中。

交互式 Author: Zemeng Feng 2023-08-23
# python select_python.py # 按提示输入： # ① POSCAR 根目录 # ② 是否随机抽取 (y/n) # ③ 抽取数量 # ④ 输出目标目录

select_XDATCARS.py

递归搜索所有 XDATCAR 文件，复制到目标目录下按序号命名的子文件夹中。

交互式
# python select_XDATCARS.py # 按提示输入： # ① 搜索 XDATCAR 的根目录 # ② 输出目标目录

select_pick_structure.py

读取 structures.xyz，通过 NEP 描述符 + PCA 降维进行结构筛选：查看全部分布、最远点采样选取、或 PCA 空间矩形区域选取。

sys.argv
# 模式 1 — 绘制全部 PCA 散点: python select_pick_structure.py all # → 生成 all-points.png # 模式 2 — 最远点采样选取: python select_pick_structure.py select <min_d1> <min_d2> ... # → 生成 selected_*.xyz / abandoned_*.xyz # 模式 3 — PCA 矩形框选取: python select_pick_structure.py pick <x1_start> <x1_end> <y1_start> <y2_end> ... # → 生成 picked.xyz / retained.xyz

compare_similar_v230721_副本.py v1.0

使用 pymatgen StructureMatcher 检测目录中的相似/重复 POSCAR 结构，将相似结构移入 SimilarStruc_* 子目录。

argparse Author: Guanjie Wang v1.0
python compare_similar_v230721_副本.py [-d <dir>] [-b <batch_size>] [-p <prefix>] # -d 目标目录，默认 ./gpuc300 # -b 批大小，默认 50 # -p POSCAR 前缀名，默认 POSCAR # 示例: python compare_similar_v230721_副本.py -d ./my_structures -b 100 -p CONTCAR

nep_plot.py

读取 NEP 训练输出文件，生成诊断图：损失曲线、能量/力/virial 散点对比、参数直方图。输出 test_result.jpg, train_result.jpg, Histogram.jpg。

无参数 — 直接运行
# 在 NEP 训练目录下直接运行: python nep_plot.py # 需确保以下文件在当前目录: # loss.out # energy_test.out, force_test.out, virial_test.out # energy_train.out, force_train.out, virial_train.out # nep.restart # 输出: # test_result.jpg — 测试集对比散点 # train_result.jpg — 训练集对比散点 # Histogram.jpg — 参数直方图
